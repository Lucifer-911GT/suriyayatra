# suriyayatra

คำนวณตามคัมภีร์**สุริยยาตร์** (ระบบโหราศาสตร์และปฏิทินไทยดั้งเดิม) ด้วย TypeScript ไม่มี dependency ใช้ได้ทั้งเบราว์เซอร์และ Node.js

> **ขั้นที่ 1 (เวอร์ชันนี้): ปฏิทินจันทรคติไทย** — หรคุณ กัมมัชพล อวมาน เถลิงศก ปีอธิกมาส/อธิกวาร ข้างขึ้น/แรม ค่ำ เดือน วันพระ และวันสำคัญทางพุทธศาสนา
> ขั้นถัดไป: สมผุสอาทิตย์ จันทร์ ราหู เกตุ → ดาวเคราะห์และมฤตยู → ลัคนา (อันโตนาที)

```bash
npm install suriyayatra
```

```ts
import { toThaiLunar, fromThaiLunar, buddhistHolyDays, holyDays, eraYear, yearType } from 'suriyayatra';

toThaiLunar({ year: 2026, month: 11, day: 24 }).label;   // "ขึ้น 15 ค่ำ เดือน 12"
toThaiLunar(new Date());                                 // a Date is read as Thai time (UTC+7)

buddhistHolyDays(2569).asalhaBucha;                      // { year: 2026, month: 7, day: 29 } — เดือน 8 หลัง
holyDays({ year: 2026, month: 11, day: 1 }, { year: 2026, month: 11, day: 30 }); // วันพระ 3, 9, 17, 24

yearType(1388);                                          // "adhikamas" (พ.ศ. 2569)
eraYear(1388);                                           // { horakhun: 506980, kammacaphon: 311, avoman: 602, tithi: 29, … }

fromThaiLunar({ cs: 1388, month: 8, secondEighth: true, phase: 'waning', day: 1 }); // วันเข้าพรรษา 2569
```

## วิธีคำนวณ

ปีจันทรคติเริ่มที่ **ขึ้น 1 ค่ำ เดือน 5** และนับด้วยเลขจุลศักราช (จ.ศ. = พ.ศ. − 1181)

1. **เลขเกณฑ์เถลิงศก** ของ จ.ศ. นั้น
   - หรคุณ = ⌊(จ.ศ. × 292207 + 373) / 800⌋ + 1 · กัมมัชพล = 800 − เศษ
   - อวมาน = (หรคุณ × 11 + 650) mod 692 · ดิถี = (⌊(หรคุณ × 11 + 650) / 692⌋ + หรคุณ) mod 30
2. **ชนิดปี**
   - อธิกมาส (384 วัน, มีเดือน 8 สองหน): ดิถีเถลิงศก > 24 หรือ < 6 (ยกเว้น ดิถี 24 ที่ปีถัดไปเป็น 6 ถือเป็นอธิกมาส และ ดิถี 25 ที่ปีถัดไปเป็น 5 ไม่เป็น)
   - อธิกวาร (355 วัน, เดือน 7 มี 30 วัน): กัมมัชพล ≤ 207 และอวมาน ≤ 126 หรือ กัมมัชพล > 207 และอวมาน ≤ 137
   - ปีเดียวกันเป็นทั้งสองอย่างไม่ได้ อธิกวารเลื่อนไปปีถัดไป
3. **ความยาวเดือน** เดือนคี่ 29 วัน (เดือนขาด) เดือนคู่ 30 วัน (เดือนเต็ม) วันพระคือ ขึ้น 8, ขึ้น 15, แรม 8 และวันสุดท้ายของเดือน (แรม 14 หรือ 15)
4. **ข้อยกเว้นทางการ** ปีที่ปฏิทินที่ประกาศใช้จริงต่างจากกฎ อยู่ใน `OFFICIAL_YEAR_TYPES` ตอนนี้มีปีเดียวคือ จ.ศ. 1376 (พ.ศ. 2557) ซึ่งกฎให้อธิกวาร (อวมาน = 137 พอดี) แต่วันสำคัญของปีก่อนและหลังเข้ากันได้เฉพาะเมื่อปีนั้นเป็นปกติมาส

ทุกค่าที่ใช้ตรวจมาจากแหล่งที่เผยแพร่แล้ว ไม่ได้มาจากโค้ดนี้เอง (`test/data.ts`)

| ชุดข้อมูล | ผล |
|---|---|
| ตัวอย่างคำนวณ จ.ศ. 1325 และ 1320 ใน Eade (2000) | ตรงทุกค่า |
| วันเถลิงศกและชนิดปีจากประกาศสงกรานต์ พ.ศ. 2569 | ตรง (16 เม.ย. 2569, อธิกมาส) |
| ข้างขึ้น/แรม ค่ำ เดือน ของวันพระและวันสำคัญ ปี 2567 และ 2569 (20 วัน) | ตรงทั้งหมด |
| มาฆะ วิสาขะ อาสาฬหบูชา ตามปฏิทินทางการ 2567–2569 (7 วัน) | ตรงทั้งหมด |
| ตารางวันสำคัญ พ.ศ. 2539–2566 จากปฏิทิน 100 ปี (84 วัน) | ตรง 81 วัน · ต่าง 1 วันเฉพาะ วิสาขบูชา 2540, 2543 และอาสาฬหบูชา 2548 ซึ่งปีข้างเคียงตรงหมด จึงน่าจะเป็นความคลาดของตาราง |

ตารางเดียวกันสำหรับปี 2567 เป็นต้นไปพิมพ์ไว้ตั้งแต่ 2550 และต่างจากปฏิทินทางการ 1 วัน เราจึงตรวจปีเหล่านั้นกับวันทางการแทน

**ข้อจำกัด**: ปฏิทินที่ประกาศจริงอาจปรับต่างจากกฎในบางปีเหมือนปี 2557 ปีอนาคตที่ยังไม่ได้ประกาศจึงเป็นค่าตามกฎ รองรับ จ.ศ. 1250–1600 (ราว ค.ศ. 1888–2238) ปีเก่ากว่านั้นการใช้กฎในอดีตต่างกันไป ถ้าเจอวันที่ไม่ตรงปฏิทินหลวง เปิด issue พร้อมแหล่งอ้างอิงได้เลย

## English

Thai **suriyayatra** calculations in dependency-free TypeScript. Version 0.1 covers the Thai lunar calendar: the Chula Sakarat year arithmetic (horakhun, kammacaphon, avoman, tithi), adhikamas / adhikawan years, Gregorian ↔ Thai lunar dates, holy days (wan phra) and the Buddhist holidays. Planet positions and the ascendant come next.

It is checked against published data only — Eade's worked examples, the official Songkran announcement, official holy days 2567–2569 and an almanac table for 2539–2566 (see the table above and `test/data.ts`). One year, CS 1376 (2014), follows the published calendar rather than the rule; it is listed in `OFFICIAL_YEAR_TYPES`.
